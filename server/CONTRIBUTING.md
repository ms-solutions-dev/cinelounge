# Contributing

Thank you for helping. Bug reports, new portals and pull requests are welcome.

## Before you start

- **Bugs:** open an issue with the server version, the portal and the steps that lead to the problem.
- **New portals:** start from `portals/beispiel` and `docs/SDK.md`. Only portals for content that may be streamed legally belong in this repository.
- **Larger changes:** open an issue first, so we can agree on the approach before you invest time.

## Contributor License Agreement

Before we can merge your first pull request, you need to sign our [Contributor License Agreement](../CLA.md). You keep the copyright in your work.

A bot comments on your first pull request. Reply with the sentence it asks for, and you are done.

## Pull requests

- Keep each pull request focused on one change.
- `ruff check`, `ruff format --check`, `mypy cinelounge`, `lint-imports` and `pytest` must pass.
- Add or update tests for behaviour you change.
- Write commit messages in English.
